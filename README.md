# FACTS — AI-Powered Stale-Answer Detector

**Can you trust that an answer is still true today?**

Facts is an AI-powered information verification application designed to help users determine whether information is accurate, relevant, and still up to date.

In a world where AI tools can confidently generate answers using outdated information, Facts helps users examine information by submitting text or links for verification.

🌐 **Live Application:** https://facts.bolt.host

---

## 💡 The Problem

AI-generated answers are not always current.

An AI system might provide information that was once correct but has since become outdated. This can happen with changing policies, statistics, prices, technology, public information, and other time-sensitive topics.

The problem is not always that the information is completely false. Sometimes, it was true at one point but is no longer accurate today.

**How can we determine whether the information we receive is still relevant and accurate?**

## 🚀 The Solution

Facts provides an AI-powered approach to examining and verifying information.

Users can submit a paragraph, a piece of text, or a URL for verification. The application uses AI and web research capabilities to help assess the submitted information and identify information that may be inaccurate or outdated.

The goal is to go beyond traditional fact-checking by considering whether information is still reliable today.

## ✨ Key Features

- **Text Verification:** Submit paragraphs or pieces of text for verification.
- **URL Verification:** Provide a web link for examination.
- **Freshness Detection:** Focuses on identifying information that may have become outdated.
- **AI-Powered Analysis:** Uses AI to assist with evaluating submitted information.
- **Web Research:** Supports checking information against relevant web sources.
- **Simple User Experience:** An accessible interface for submitting information and reviewing results.

## ⚙️ Technology Stack

Facts integrates AI infrastructure and web research capabilities to support its verification process.

### Bifrost
[Bifrost](https://www.getbifrost.ai/) serves as the AI gateway, providing the connection between the application and its AI model.

### Tavily
[Tavily](https://www.tavily.com/) provides web search and research capabilities, helping the application retrieve relevant information from the web for verification.

### AI Model
The application uses GPT-4o through the Bifrost integration to support AI-powered analysis.

## 🔄 How It Works

1. **Submit Information:** The user pastes a paragraph, text, or URL into Facts.
2. **AI Analysis:** The application uses its AI integration to examine the submitted information.
3. **Web Research:** Tavily provides web research capabilities to help retrieve relevant information.
4. **Verification:** The application uses the available information to assess the accuracy and freshness of the submitted content.
5. **Review Results:** The user receives the verification output.
